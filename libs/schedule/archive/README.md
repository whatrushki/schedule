# Архив устаревших парсеров вузов (`:libs:schedule:archive`)

Данный модуль содержит исходный код старых парсеров расписаний и новостей до перехода на `foundation-scraper` DSL:
- `dgtu`
- `iubip`
- `rgups`
- `rgups_tuapse`
- `rinh`
- `rksi`
- `sfedu`
- `tvgu`

⚠️ **ВАЖНО:** Этот модуль **отключен от продакшн сборки** и предназначен исключительно для справки, сверки поведения, отладки и истории.
